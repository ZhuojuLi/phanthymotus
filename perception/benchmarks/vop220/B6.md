# B6 coverage expansion candidate

This submission keeps the 220-class vocabulary, FP16 640 input, one-to-many
head, class-aware NMS at 0.7, confidence 0.35, and max_det 300. It replaces
only the model bundle; the product inference and scoring paths are unchanged.

B6 starts from B5's 70/30 interpolation. An isolated classification branch for
20 classes is trained for a fixed six epochs, using 587 reviewed positive and
166 verified-negative additional images with organizer and COCO replay. Other
parameters and box regression remain fixed. Class-scope masks avoid treating
unannotated classes as background. Training weights are not shipped in Git.

Fixed local evaluation at IoU 0.7:

| Evaluation | B5 | Same-budget old-data control | B6 |
| --- | ---: | ---: | ---: |
| Organizer107, full vocabulary assumption | 46.572% | 46.443% | 46.907% |
| COCO200 | 57.671% | 57.671% | 57.705% |
| New194, reviewed focus classes only | 48.980% | 44.444% | 56.250% |

Organizer improvement is small and concentrated in a few images; it is not a
claim of a statistically established gain. New194 is not a complete220 gold
set or independent human annotation. These are local results, not competition
scores. The candidate is submitted to measure actual competition behavior.
